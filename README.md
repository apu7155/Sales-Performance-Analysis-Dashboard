# 📊 Sales Performance Analysis Dashboard

## Project Overview

This project presents an interactive Sales Performance Analysis Dashboard designed to explore sales records across multiple business dimensions.

The dashboard allows users to analyze sales performance by **payment method, region, city, month, and product category**.

## Objective

The objective of this project is to transform sales records into an interactive dashboard that makes it easier to identify sales patterns, compare different business segments, and monitor overall sales performance.

## Tools & Technologies

Microsoft Excel | Power Query | Power BI | DAX | Data Visualization

## Analysis Areas

- Payment Method Analysis
- Regional Sales Analysis
- City-wise Sales Analysis
- Monthly Sales Analysis
- Category-wise Sales Analysis
- Overall Sales Performance

## 🔍 Key Business Questions

- Which payment methods generate the highest sales?
- Which regions and cities perform better?
- How does sales performance change across months?
- Which product categories contribute most to sales?
- How does overall sales performance vary across different segments?

## 💡 Key Insights

- Analyzed sales performance across different payment methods.
- Compared sales performance across regions and cities.
- Identified monthly sales trends and variations.
- Evaluated category-wise sales performance.
- Enabled interactive filtering to explore sales records from multiple perspectives.
